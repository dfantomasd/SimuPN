# SimuPN

Автоматически обновляемая подписка VLESS для Happ и Karing. SimuPN собирает
узлы из независимых источников, удаляет дубликаты, проверяет туннель и сервисы,
а затем поднимает стабильные быстрые узлы выше перегруженных резервов.

## Источники

Источники задаются в `sources.json`. Короткое поле `short` показывается в имени
каждого сервера, например `[LIB]`, `[AUX]`, `[VOV]` или `[FRE]`. Один и тот же VLESS-узел, найденный у
нескольких поставщиков, публикуется один раз с меткой первого источника.

Для временного запуска список URL можно передать через переменную окружения
`SIMUPN_SOURCE_URLS`, разделяя адреса запятыми.

Большие публичные каталоги ограничиваются параметром `max_nodes`. Выборка
детерминированно меняется раз в сутки: SimuPN постепенно проверяет весь каталог,
не пытаясь одновременно поднять тысячи Xray-туннелей.

## Контроль перегрузки

Каждый узел проходит три последовательных загрузки по 512 КиБ через настоящий
Xray-туннель. Используется медианная скорость. Узел получает отметку
`🟠 резерв`, если медиана ниже 3 Мбит/с или отношение худшего результата к
лучшему ниже 0,45. Резервы остаются в подписке после основных узлов, чтобы
временная перегрузка не оставила пользователя совсем без подключения.

Не отвечающий узел удаляется после трёх последовательных сбоев и возвращается
только после двух успешных проверок. Если отдельный источник недоступен или
неожиданно потерял большую часть серверов, используется его последняя
сохранённая копия.
